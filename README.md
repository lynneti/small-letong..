small letong

Welcome. This is a website that I made to cherish one of the best experiences I've had — some of the most amazing time and people I spent time with in 2026, from May to August, during my internship at Alibaba.

About

A single-screen interactive page. Click START and look around — the faces, the objects, and the days are all pieces of those four months.

It's built as one index.html file with no frameworks, no build step, and no dependencies. Just HTML, CSS, and a folder of images.

Running it locally

Clone the repo and open index.html in a browser. That's all it needs.

bash
git clone https://github.com/lyn75/small-letong.git
cd small-letong
open index.html
Structure
index.html      — the whole site: markup, styles, and behaviour
assets/         — photos, faces, and objects
